# Stoic Podcast for Omarchy

An unofficial Omarchy Quattro player for the public Daily Stoic podcast feed.

## Content and affiliation

This project contains only client software. It does not include, host, proxy,
archive, transcribe, or license podcast content. Audio is streamed directly
from the enclosure URL published by the podcast's official RSS feed.

Daily Stoic, Ryan Holiday, associated artwork, and podcast content belong to
their respective owners. This project is not affiliated with or endorsed by
Daily Stoic, Ryan Holiday, Backyard Ventures, or Penguin Random House.
